# DECODELABS

The first document contains presents the Social Media Content Plan for “Virtual Tami”, a digital virtual assistance and marketing services brand. The plan covers a 30-day structured content strategy across four key platforms: LinkedIn, Instagram, Twitter/X, and Instagram Stories. It maps audience segments, defines content pillars, and provides a week-by-week posting schedule built on the psychological funnel framework, moving the audience from Problem Awareness through to Conversion. The plan is designed to build brand trust, demonstrate expertise, and attract both individual and business clients.
The second document presents the SEO Basics and Keyword Research deliverable for Virtual Tami, a digital virtual assistance and marketing services brand based in Nigeria. The goal of this project is to identify 20 verified keywords that can drive organic traffic to the Virtual Tami website or blog, categorise each keyword by search intent, estimate search volumes, and calculate KGR (Keyword Golden Ratio) scores to prioritise low-competition opportunities. The research also maps each high-priority keyword to a specific content or page recommendation, and demonstrates on-page SEO placement principles through worked examples.
The last document demonstrates the application of content writing and on-page SEO principles through the creation of an optimized blog article for the Virtual Tami brand. The selected target keyword is “What Does a Virtual Assistant Do?”, identified during Project 2 as a high-potential informational keyword with strong search demand.The article is structured using proper heading hierarchy, natural keyword placement, and reader-friendly formatting to improve both user experience and search engine visibility.
